# Agent instructions

- Keep this repository limited to functional source, generic tools and product
  documentation. Use fictitious example identities and reserved example routes.
- Do not add conversations, personal deployment inventories, machine-specific
  reports, credentials, private paths or local environment metadata.
- Review all files and commit metadata before publication. Do not import an
  unrelated repository's history or indiscriminately mirror another remote.
- Use Rust and preserve the hubless peer architecture. Do not introduce an AI
  runtime service, mandatory central coordinator or additional user password.
- Existing identities, keys and layout are user data; installation must not
  overwrite them. Keep generated security material outside the checkout.
- Read the installation and scenario documentation before configuring nodes.
- Keep source/build validation separate from installed runtime and physical
  acceptance. Synthetic input does not establish real keyboard/mouse acceptance.
- No GitHub Actions, CI/CD, Vercel or scheduled automation is required or enabled.
- Write code, comments and documentation in English.
